# EtherNet/IP 相机侧配置（IDMVS）

相机接 PLC 之前，先把相机自己这一侧配好：模式、协议使能、组件大小、结果输出格式。这四处只要有一处不对，PLC 侧配得再准也拿不到条码。

## 一、先确认前提

| 项目 | 要求 |
| --- | --- |
| 相机固件 | V2.3.0 及以上 |
| 设备型号 | 支持 EtherNet/IP 的 ID 系列读码器 |
| EDS 文件 | 2021/10/14 及以后的版本 |
| 网络 | 相机与 PLC 在同一网段，能互相 ping 通 |

固件太老时，EIP 相关的配置项可能不出现，或者连接第三方 PLC 时表现不正常。EDS 文件虽然用在 PLC 侧，但版本不对同样会导致相机加不进工程，配置前一起确认。

## 二、切到 Normal 模式

用 IDMVS 连上相机后，把顶部的模式下拉从当前模式切成 **Normal**，触发可以先选 **software** 模式。

如果进通信配置时弹出「配置通讯参数请切换至 Normal 模式」，说明相机还在别的模式下，切过去再回来配。

## 三、打开 EIP 使能，设定组件大小

进入通信配置，把通信协议选成 **EthernetIp**，再按下图把 EIP 这几项设好。

![IDMVS 通信配置中的 EthernetIP 参数：协议使能开关、输入输出组件 200、结果超时 10](/images/communication/eip-camera-config/fig-02-eip-enable.webp)

- **EthernetIP 协议使能**：打开。关着的时候相机不响应 PLC 的扫描，设备列表里找不到它。
- **EthernetIP 输入组件 / 输出组件**：填 **200**，单位是**字节**，图中是常用示例值。两个值要一致，也要和 PLC 侧建的全局变量大小一致。
- **EthernetIP 结果字节交换**：条码内容出现高低字节错乱时再打开。
- **EthernetIP 结果超时**：图中填 10（秒）。节拍慢、或者一次触发要连拍多帧时，适当调长。

> 组件大小按字节算，PLC 侧按字算。200 字节要在 PLC 里留够 100 个字，别只按名字对上、长度却差一半。

## 四、配置结果输出内容

同一个通信配置界面往下拉，是结果输出的格式定义。

![EthernetIP 输出格式面板：格式化标志 <code_content>、输出前后缀、输出无读 NoRead](/images/communication/eip-camera-config/fig-03-output-format.webp)

- **输出格式化标志**：必须写 `<code_content>`。这一栏空着，结果区里就没有条码内容，只剩状态位。
- **输出开始 / 输出结束**：可选的前后缀，示例里是 `<p>` 和 `</p>`。加了前后缀，PLC 取到的是带包装的字符串，解析时要一起处理。
- **输出无读**：打开后，没读到码时输出 `NoRead` 字符；关掉时，没读到码就直接反馈 Results NG，两种情况的 PLC 判断逻辑不同，见下面说明。
- **格式化检查**：点「执行」，返回 `<success>` 才说明格式串合法。

> 使能 NoRead 且没读到码时，相机反馈 **Results OK + "NoRead"** 字符；关闭 NoRead 且没读到码时，反馈 **Results NG**。PLC 侧判断逻辑要按这个区别来写，否则会把没读到当成读到了。

## 五、配置完成后打开取流

输出配置改完，最后一步是**打开取流**，顺序别反了：先配置，再取流。开着取流时，在历史记录里确认能正常出码、码内容与格式串一致，再去 PLC 侧组态。

只连着 IDMVS 却没开取流，触发往往不会有结果，看起来就像「配置好了但没反应」；如果相机平时不接客户端运行，要在相机里打开自动工作使能。

参数改完后记得保存用户参数，否则重新上电会回到旧配置。

## 六、和 PLC 侧怎么对上

相机侧定好的三件事，PLC 侧必须一一对应：

| 相机侧 | PLC 侧 |
| --- | --- |
| 输入组件 200 字节 | 输入映像区留够 100 个字 |
| 输出组件 200 字节 | 输出映像区留够 100 个字 |
| 结果格式含 `<code_content>` | 从 `DataIn[20]` 开始读条码内容 |

握手时序、映像区每一位的定义，以及清错、报错位的处理，见 [EtherNet/IP 通讯排查（含汇川 PLC）](#/article/ethernet-ip-troubleshooting) 和 [PLC 通讯寄存器与状态位基础](#/article/plc-register-basics)。
