# PLC 与 Profinet / EtherNet/IP 集成

读码器接入 PLC 后，触发、结果和状态都进入产线控制逻辑。集成前先确认协议支持和数据长度。

## 一、确认协议

- 读码器是否支持 Profinet / EtherNet/IP。
- PLC 侧是否已有对应 GSDML/EDS 文件。
- 数据宽度是否够放码内容。
- 是否需要独立的触发位和完成位。

> IDH9000 等型号公开资料中列出 TCP、FTP、Profinet、EtherNet/IP 等协议；固定式型号的支持清单以官方手册为准。

## 二、组态步骤

1. 在 PLC 工程中导入 GSDML/EDS。
2. 分配设备名称与 IP。
3. 配置输入/输出数据长度。
4. 映射触发位、结果区、状态位。
5. 下载组态，检查设备在线。
6. 做触发与结果握手测试。

## 三、握手时序

推荐使用“触发—忙—完成”三段式：

```text
PLC: 置触发位
读码器: 开始读码，置忙
读码器: 读码完成，写结果，置完成
PLC: 读取结果，清触发
读码器: 清完成，等待下一次
```

要避免：

- PLC 未清触发就再次触发
- 读码器未完成就覆盖结果
- 结果区没有校验位
- 通信中断后状态位卡死

## 四、数据映射建议

| 区域 | 内容 |
| --- | --- |
| 输出到读码器 | 触发、参数切换、复位 |
| 输入到 PLC | 状态、码长度、码内容、错误码 |

码内容通常需要多个字，注意字节序和字符串编码。

## 五、常见问题

- **设备不在线**：设备名称、IP、GSDML 版本不匹配。
- **触发无反应**：映射地址错、触发位未保持、握手未清。
- **结果截断**：数据长度不足或字节序错误。
- **偶发掉线**：网络干扰、交换机配置、接地问题。

## 六、验收

- [ ] 设备在线稳定
- [ ] 触发/完成握手正确
- [ ] 结果长度与编码正确
- [ ] 断线恢复后状态可复位
- [ ] 与产线节拍匹配
