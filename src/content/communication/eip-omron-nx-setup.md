# EtherNet/IP PLC 侧配置（欧姆龙 NX 系列）

相机侧配好之后，PLC 侧要做的就一件事：把相机加进 EtherNet/IP 连接，让它和两块 200 字节的全局变量对上。下面以 NX102-9000 + Sysmac Studio 为例。

## 一、先确认前提

| 项目 | 要求 |
| --- | --- |
| 相机固件 | V2.3.0 及以上，型号支持 EtherNet/IP |
| EDS 文件 | 2021/10/14 及以后的版本 |
| 软件 | Sysmac Studio，电脑能连到 PLC |
| 网络 | 相机 IP 已知，与 PLC 同一网段 |

## 二、先看硬件端口

![欧姆龙 NX102-9000 的网口：PORT1、PORT2 支持 EtherNet/IP，PORT3 为 EtherCAT，图中网线插在 PORT1](/images/communication/eip-omron-nx-setup/fig-01-nx102-ports.webp)

- **PORT1 / PORT2** 支持 EtherNet/IP，**PORT3** 是 EtherCAT。
- 插哪个口，软件里就配哪个口的 IP。图中网线在 PORT1。
- 面板上 NET RUN / NET ERR 两个灯能直接看出 EIP 链路状态：NET RUN 绿说明通讯在跑。

## 三、新建工程并开启 DM 区域

1. 打开 Sysmac Studio，新建工程，命名后控制器类型选 **NX102**、型号按实际（示例 9000）、版本按设备实际选择，点创建。
2. 依次进入 **配置和设置 → 控制器设置 → 内存设置**，找到 **DM** 这一行，勾选启用。

DM 区不启用，后面给变量分配 `%D` 地址会失败，这一步别跳。

## 四、建两个全局变量

依次点 **编程 → 数据 → 全局变量**，建两个变量：

| 变量名 | 数据类型 | 分配地址 | 保持 | 网络公开 |
| --- | --- | --- | --- | --- |
| DataIn | ARRAY[0..199] OF BYTE | %D100 | 勾选 | 输入 |
| DataOut | ARRAY[0..199] OF BYTE | %D0 | 勾选 | 输出 |

- 数据类型按字节数组建，长度 200，要和相机侧的组件大小一致。
- 地址单位是**字**，组件单位是**字节**：200 字节占 100 个字，两个变量的起始地址至少隔开 100 个字。示例里 DataOut 从 `%D0` 起、DataIn 从 `%D100` 起，正好不重叠。
- **保持**要勾上，否则断电后数据不保留；**网络公开**分别选输入、输出，否则 EIP 侧看不到这两个变量。

> 地址间隔按组件大小的一半算，写错会出现地址重叠：比如输入给了 `%D100`，输出还从 `%D50` 起，两块内存就压在一起了。

## 五、设置 EIP 端口 IP

依次进入 **配置和设置 → 控制器设置 → 内置 EtherNet/IP**，选接相机的那一路端口，固定设置里填 IP 和子网掩码，与相机保持同网段。

一台 PLC 有两个 EIP 口时，别把相机接在 PORT1、软件里却配了 PORT2。

## 六、安装 EDS 文件

![EDS 库：装好之后在 Hik Robot → Hikrobot smart camera 下能看到 ID2000、ID3000、ID5000](/images/communication/eip-omron-nx-setup/fig-02-eds-library.webp)

1. 菜单 **工具 → EtherNet/IP 连接设置**，双击要用的端口。
2. 在工具箱里右键，选 **显示 EDS 库**。
3. 点 **安装**，选中对应型号的 EDS 文件，装完会在 **Hik Robot → Hikrobot smart camera** 下出现 ID2000 / ID3000 / ID5000。

装完的型号对不上，说明 EDS 版本旧了，换 2021/10/14 之后的版本重装。

## 七、把相机加进连接

1. 工具箱里点 **+**。
2. **节点地址**填相机的 IP，**型号名称**选相机大类（示例 **ID5000**），**修订版**保持默认 **1**。
3. 点 **添加**，成功后目标设备列表里会出现这台相机，IP、型号、版本都对得上。

点添加没反应，先确认节点地址与 PLC 在同一网段、相机已上电并 ping 得通。

## 八、绑定全局变量

点连接图标，用 **+** 添加设备，把两块变量绑到相机上：

| 方向 | 目标变量 | 大小（字节） | 起始变量 |
| --- | --- | --- | --- |
| 输入 | 13 | 200 | DataIn |
| 输出 | 22 | 200 | DataOut |

- **目标变量**的 13 / 22 是 EDS 里固定的组件号，不能改；能改的是后面的变量和大小。
- 大小填 **200**，与相机侧一致；起始变量选第四步建的 DataIn / DataOut。
- 其余保持默认，连接类型 Point to Point、RPI 50.0 ms。

## 九、把工程同步进 PLC

1. 工具栏依次点 **编译 → 在线 → 同步**。
2. 在同步窗口点 **传送至控制器**，弹窗全部选「是」，传完点关闭。
3. 回到 **EtherNet/IP 连接设置** 界面，再点一次 **传送至控制器**，选「在运行模式下执行传送」。EIP 连接是在这一步才真正写进 PLC 的。

只做前两步，工程进去了但连接配置没进去，现象就是程序在线、相机却一直不在线。

## 十、验收清单

- 目标设备在线，面板 NET RUN 灯常绿。
- 监视表能读到 DataOut、DataIn，写入 DataOut[0] 相机会响应。
- 触发一次，DataIn[3] 出现 Result OK，DataIn[20] 起有字符。

监视表的用法、握手时序和常见问题见 [EtherNet/IP 通讯测试：监视、触发与握手时序](#/article/eip-comm-test-handshake)；相机侧的对应设置见 [EtherNet/IP 相机侧配置（IDMVS）](#/article/eip-camera-config)。
