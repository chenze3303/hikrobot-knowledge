# 3C 电子 DPM 读码：小视野、低对比度怎么打

3C 行业的读码对象往往很小：PCB 上的 Data Matrix、金属中框上的激光码、塑胶件上的点阵码。码小、对比度低、背景纹理复杂，是主要难点。

## 一、先解决光学

### 光源选择

| 场景 | 建议 |
| --- | --- |
| 金属镜面 | 同轴光或偏振光，压制反光 |
| 点阵/激光打标 | 低角度光，强化凹凸边缘 |
| PCB 阻焊层 | 漫射环形光，降低纹理干扰 |
| 高反光小零件 | 穹顶光或多次曝光 |

### 镜头与视野

- 优先保证最小模块有 3 个以上像素。
- 视野不要为了“兼容大件”放得过大。
- 小视野下景深更浅，要控制工件高度波动。

## 二、再调算法

- 启用 DPM 模式。
- 适当提高图像增强和对比度。
- 设置 ROI，排除无关纹理。
- 多码场景设定读取区域和输出顺序。
- 对低质量码启用更高的纠错和重试。

## 三、安装与节拍

- 固定式读码器尽量正对码面，避免大角度倾斜。
- 工件定位重复性要足够，否则码会跑出 ROI。
- 若工件在运动，先算拖影，再决定曝光和补光。
- 多工位共用一台设备时，确认切换节拍不会丢触发。

## 四、验收标准

建议按以下维度验收：

- 正常来料连续 100 次读码率
- 最差来料连续 100 次读码率
- 不同班次/不同供应商来料的一致性
- 误读率与重复读处理
- 与 MES 的数据对接正确率

> 只测“能读”没有意义，3C 产线要的是稳定读码率和可追溯的数据闭环。
