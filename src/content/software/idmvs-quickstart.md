# IDMVS 客户端快速上手

IDMVS 是海康机器人读码器的配置与调试客户端。版本和界面会更新，但核心流程稳定：连接设备、出图、调参、触发、保存。

## 一、安装与连接

1. 从官方下载中心获取对应版本的 IDMVS。
2. 安装后启动，选择设备接口类型。
3. 刷新设备列表，选中读码器并连接。
4. 如果设备不在线，先排查网络或 USB 连接，不要反复重装软件。

> 不同系列可能对应不同大版本的 IDMVS，安装前确认兼容性。

## 二、实时预览与对焦

连接后先看实时图：

- 码是否完整在视野内
- 亮度是否均匀
- 边缘是否锐利
- 是否有拖影或反光斑

调焦时放大码区，缓慢调整直到边缘最清晰。对焦完成后再调曝光和增益。

## 三、曝光与增益

| 调整 | 效果 | 副作用 |
| --- | --- | --- |
| 增加曝光时间 | 图像变亮 | 运动拖影、帧率下降 |
| 增加增益 | 图像变亮 | 噪声增加 |
| 增强补光 | 图像变亮 | 散热、反光、功耗 |
| 缩小光圈 | 景深变大 | 进光量减少 |

优先用曝光和光源解决问题，增益只做小幅补偿。

## 四、触发设置

路径通常为：

```text
I/O Control Settings → Input → Trigger Mode
```

- 内触发：Trigger Mode = Off
- 软件触发：Trigger Mode = On，Trigger Source = Software
- 硬件触发：选择对应输入线
- TCP 触发：Trigger Source = TCP Start，设置端口和触发字符串

## 五、读码参数

至少确认：

- 码制是否勾选
- 最小模块/精度
- ROI 区域
- 多码与去重
- DPM 模式
- 结果输出格式

## 六、保存与备份

1. 先保存到本地工程，便于版本管理。
2. 再保存到设备，确保断电后生效。
3. 导出配置文件，按“日期+型号+工位”命名。
4. 记录本次参数变更，方便回退。

## 七、常见问题

- **连不上**：网段、防火墙、IDMVS 版本、网卡选择。
- **能出图不能读**：码制、ROI、曝光、最小模块。
- **参数重启丢失**：没有保存到设备。
- **换工位后效果差**：安装距离、光源、工件位置变了，需要重新调参。
