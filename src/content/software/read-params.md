# 码制、DPM 与多码参数

读码参数的目标不是“能读”，而是“稳定、可控、可解释”。

## 一、码制

只勾选现场实际使用的码制：

- 全部勾选会增加处理时间，也可能增加误读。
- 一维码要关注最小条宽和方向。
- 二维码要关注模块大小和纠错等级。
- 多码制混线时，按工位分别保存参数。

## 二、DPM 模式

DPM 码需要单独启用：

- 图像增强
- 对比度提升
- 二值化策略
- 读取超时与重试

> DPM 参数要拿实际工件调，不要用标准测试卡代替。

## 三、ROI 与读取区域

- ROI 越小，处理越快，但工件漂移容易跑出区域。
- 多工位共用时，按工位设置不同 ROI。
- 多码场景要限定读取区域，避免读到背景上的其他码。
- ROI 边缘要留余量。

## 四、多码与顺序

| 需求 | 配置 |
| --- | --- |
| 只读一个码 | 限定 ROI，设置优先级 |
| 读多个码 | 开启多码，设置最大数量 |
| 固定顺序输出 | 按区域顺序或码内容排序 |
| 避免重复 | 开启去重，设置时间窗 |

## 五、去重与过滤

常见过滤规则：

- 同一码在 N 毫秒内只输出一次
- 只输出符合长度/前缀的码
- 校验位失败不输出
- 低质量结果不输出

去重要放在读码器或上位机其中一端，不要两端规则冲突。

## 六、输出格式

至少确认：

- 分隔符
- 是否带换行
- 多码拼接顺序
- 时间戳与工位号
- 失败时的输出内容

## 七、参数版本管理

建议每个工位保存：

- 参数文件
- 对应工件照片
- 调参记录
- 验收读码率

换型或换供应商时，能快速回退和对比。
