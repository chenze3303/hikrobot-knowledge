# 固件升级与回退

固件升级不是“越新越好”。产线设备要优先稳定，升级前必须确认版本、兼容性和回退路径。

## 一、升级前

1. 记录当前固件版本。
2. 导出当前参数配置。
3. 确认新固件适配当前型号。
4. 阅读版本说明，确认修复内容与已知问题。
5. 选择停线窗口，避免生产中途升级。

## 二、升级中

- 使用稳定供电，避免断电。
- 使用有线网络，不用无线。
- 不要同时升级多台设备，先做一台验证。
- 升级过程中不要断电、不要拔线。
- 等待设备重启完成，再重新连接。

## 三、升级后

- 核对固件版本。
- 导入或重新检查参数。
- 用实际工件复测读码率。
- 检查通讯、触发、输出格式是否变化。
- 观察 24 小时稳定性。

## 四、回退

如果新版本导致问题：

1. 确认官方是否提供回退固件。
2. 按手册进入升级/恢复模式。
3. 恢复旧固件后，导入升级前备份的参数。
4. 记录问题现象，反馈给厂商。

> 不是所有型号都支持随意回退。升级前就要确认回退方案。

## 五、版本管理建议

- 按工位记录固件版本和参数版本。
- 同一条线尽量统一版本。
- 保留升级包和校验值。
- 升级记录包含日期、人员、原因、结果。

## 六、常见问题

- **升级后连不上**：IP 可能恢复默认，检查网络配置。
- **参数丢失**：升级前未备份，或升级清除了配置。
- **读码率下降**：新固件算法或默认参数变化，需要重新调参。
- **升级失败**：断电、网络中断或固件不匹配，按恢复流程处理。
