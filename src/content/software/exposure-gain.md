# 曝光、增益与图像质量

读码率上不去时，先看图像。图像不行，算法参数只是止痛药。

## 一、曝光时间

曝光时间越长，进光越多，但运动拖影越明显。

```text
拖影 ≈ 线速 × 曝光时间
```

- 静态工位：可以适当延长曝光，换取更低噪声。
- 动态产线：优先缩短曝光，用光源补亮度。
- 50 Hz 环境光：注意频闪，曝光时间尽量避开工频周期。

## 二、增益

增益是电信号放大，会同时放大噪声。

- 优先加曝光或补光。
- 增益只做小幅补偿，通常不超过中低档。
- 增益过高会让码边缘变“毛”，反而降低读码率。

## 三、不同场景的调法

| 场景 | 优先动作 |
| --- | --- |
| 图像偏暗 | 加曝光 → 加补光 → 小幅增益 |
| 运动拖影 | 减曝光 → 加频闪 → 提高帧率 |
| 反光过曝 | 改光源角度 → 偏振/漫射 → 降曝光 |
| 低对比度 DPM | 改低角度光 → 开 DPM 增强 → 调曝光 |
| 噪声大 | 降增益 → 增曝光 → 改善光源 |

## 四、判断图像是否合格

- 码的黑白模块边界清楚。
- 背景不过曝、不死黑。
- 视野内亮度均匀。
- 最差工件也能看出码的轮廓。
- 连续多帧稳定，不闪烁。

## 五、不要做的事

1. 不要用自动曝光跑高速产线，容易忽明忽暗。
2. 不要用增益硬拉亮度。
3. 不要只看监视器画面，要导出原图检查。
4. 不要只测好工件。
