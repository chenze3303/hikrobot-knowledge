# FTP 图片与结果上传

FTP 上传常用于质量追溯、NG 留图和远程排查。配置不难，难的是长期稳定运行。

## 一、先定上传策略

| 策略 | 适用 |
| --- | --- |
| 全部上传 | 全量追溯，存储压力大 |
| 仅 NG 上传 | 节省空间，便于排查 |
| 按比例抽样 | 兼顾追溯与成本 |
| 触发后上传 | 与产线节拍绑定 |

## 二、配置要点

- FTP 服务器地址、端口、用户名、密码
- 上传目录
- 文件名规则
- 图片格式与质量
- 上传超时与重试
- 网络断开时的缓存策略

## 三、文件名建议

```text
{工位号}_{日期}_{时间}_{结果}_{码内容}.jpg
```

注意：

- 码内容可能包含 `/`、`\`、`:` 等非法字符，要替换。
- 文件名不要太长。
- 时间用统一时区。
- 多码时用序号区分。

## 四、网络与容量

- FTP 上传会占用带宽，和实时结果输出共享网络。
- 大批量图片要考虑服务器磁盘和清理策略。
- 无线网络下不要做全量图片上传。
- 上传失败要有本地缓存或重传，不要直接丢弃。

## 五、常见问题

- **能连 FTP 但传不上去**：目录权限、被动模式、防火墙。
- **文件名乱码**：编码不一致，统一使用 UTF-8 或纯英文。
- **上传拖慢节拍**：改为异步上传或仅 NG 上传。
- **磁盘很快满**：检查是否全量上传、图片是否过大。
- **图片和结果对不上**：文件名规则或时间戳不一致。

## 六、验收

- [ ] 正常读码上传成功
- [ ] NG 图片按策略上传
- [ ] 断网后恢复能补传
- [ ] 文件名可读、可检索
- [ ] 服务器容量与清理策略
