# ID2000 系列快速上手

ID2000 是面向自动化机台的紧凑型固定式读码器。本文按“先通电、再出图、后读码”的顺序，给出一条最短调试路径。

## 一、先认识接口

不同型号的接口布局会有差异，但通常包含：

- 电源与 I/O 线缆接口
- GigE 网口（部分型号为多网口或带 PoE 选项）
- 触发/输出指示灯
- 镜头与光源接口

> 接线前先核对机身丝印和手册引脚定义，不要仅凭线缆颜色判断。

## 二、七步跑通

### 第 1 步：供电与网络

1. 使用额定直流电源，确认电压和极性。
2. 网线直连工控机或接入交换机，确认链路灯亮。
3. 工控机网卡设置为与读码器同网段，或启用自动获取。
4. `ping` 读码器 IP，确认网络可达。

### 第 2 步：在 IDMVS 中枚举设备

打开 IDMVS，选择对应接口类型，刷新设备列表。如果看不到设备：

- 检查网卡是否被防火墙或安全软件拦截。
- 检查读码器与工控机是否在同一网段。
- 确认没有多个网卡使用相同网段造成冲突。

### 第 3 步：连接并出实时图

连接设备后打开实时预览。先不要急着读码，先看图像：

- 画面是否完整覆盖码区
- 亮度是否均匀
- 码是否清晰、无拖影
- 背景是否过曝或全黑

### 第 4 步：对焦

固定式读码器常见为手动调焦镜头。把码放在实际工作距离，边看实时图边调焦，直到码的边缘最锐利。

> 对焦时用实际产线样品，不要用打印在纸上的“完美测试码”。

### 第 5 步：曝光与增益

优先调曝光时间，再补增益：

- 图像偏暗：先增加曝光时间，仍不够再小幅加增益。
- 运动拖影：缩短曝光时间，同时增强补光。
- 过曝反光：降低曝光或改用偏振/漫射光。

### 第 6 步：设置触发

在 `I/O Control Settings → Input → Trigger Mode` 中：

| 模式 | 设置 | 适用 |
| --- | --- | --- |
| 内触发 | Trigger Mode = Off | 连续读码、调试 |
| 软件触发 | Trigger Mode = On，Trigger Source = Software | 上位机控制 |
| 硬件触发 | Trigger Mode = On，选择对应输入线 | 光电/PLC |
| TCP 触发 | Trigger Mode = On，Trigger Source = TCP Start | 网络触发 |

### 第 7 步：读码测试与保存

1. 放上实际样品，确认能稳定输出结果。
2. 连续触发 50–100 次，统计读码率。
3. 换用最差来料复测。
4. 保存参数到设备，并导出配置文件备份。

## 三、常见坑

- **能出图但读不到**：先确认码制是否勾选，再检查最小模块和 ROI。
- **读码率忽高忽低**：优先查触发时序和工件位置，不要只改算法参数。
- **换电脑后连不上**：检查网段、防火墙和 IDMVS 版本。
- **参数保存后丢失**：确认是“保存到设备”，不是只保存到本地工程。

## 四、示例参数

| 项目 | 示例值 |
| --- | --- |
| 分辨率 | 1920 × 1080 |
| 镜头 | 5 mm |
| 读码速度 | 80 码/秒 |
| 帧率 | 50 fps |

以上为系列示例参数，具体型号以官方规格书为准。
