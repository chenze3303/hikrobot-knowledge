# 一维码、二维码与 DPM：识别难点对照

读码器不是“什么码都能读”。码制、打印方式、载体材质和表面状态，决定了成像难度和参数重点。

## 一、三类码的核心差异

| 类型 | 典型例子 | 识别难点 | 优化方向 |
| --- | --- | --- | --- |
| 一维码 | Code 128、EAN、Code 39 | 窄条模糊、断帧、低对比度 | 足够像素、水平方向、锐利成像 |
| 二维码 | QR、Data Matrix、PDF417 | 模块变形、反光、污损 | 均匀照明、纠错等级、曝光 |
| DPM | 激光/点阵打在金属、PCB | 低对比度、纹理干扰、凹凸 | 低角度光、同轴光、DPM 算法 |

## 二、一维码

- 关键是**窄条宽度**，不是整个标签长度。
- 码方向要与传感器扫描方向匹配；固定式安装时尽量让条码横向。
- 覆膜、弯曲、划伤会造成断帧，先改善成像再调参数。
- 长码不要盲目拉大视野，否则单模块像素不足。

## 三、二维码

- QR 有纠错能力，但污损超过纠错等级仍会失败。
- Data Matrix 常见于小零件，模块小，要求更高分辨率。
- 反光表面优先用偏振光或漫射光，避免直射光斑。
- 多码场景要设置 ROI 和输出顺序，否则结果容易混。

## 四、DPM

DPM 的三个关键：

1. **对比度**：激光打标、点阵打标、蚀刻的成像差异很大。
2. **方向**：低角度光能强化凹凸边缘，同轴光适合镜面。
3. **算法**：需要启用 DPM 模式，并适当调整二值化和增强参数。

> DPM 不要只做“能读”测试，要做“连续 100 次读码率”和“最差工件”测试。

## 五、来料质量分级

建议把来料分成 A/B/C 三级：

- A：清晰、平整、对比度高
- B：轻微覆膜、弯曲或低对比
- C：划伤、污损、断帧、低对比 DPM

验收标准按 C 级来定，否则产线一换供应商就会掉读码率。

## 六、参数优先级

遇到读不到时，按这个顺序排查：

1. 码制是否勾选
2. 最小模块与像素是否匹配
3. 图像是否清晰、曝光是否正确
4. ROI 是否覆盖码区
5. DPM/增强参数是否启用
6. 触发时机是否在码完全进入视野时
