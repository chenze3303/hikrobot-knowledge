# PDA / IDP 智能终端：选型与部署要点

PDA 不是“带扫码头的手机”。它要同时承担读码、业务操作、无线漫游、续航和系统集成，任何一项短板都会在班次中途暴露。

## 一、IDP 系列看什么

以 IDP 系列为例，公开资料中可见的型号包括 MV-IDP3204/32G，标称 3 mil 最小精度、8 核处理器。选型时建议核对以下维度：

| 维度 | 要确认 |
| --- | --- |
| 读码 | 一维/二维码、DPM、最小精度、景深 |
| 系统 | 操作系统版本、是否支持 MDM |
| 性能 | CPU、内存、存储、是否卡顿 |
| 屏幕 | 尺寸、亮度、户外可读性、触控手套模式 |
| 续航 | 电池容量、可换电、充电座 |
| 无线 | Wi-Fi 频段、漫游、蓝牙 |
| 防护 | 防护等级、抗跌落、工作温度 |
| 集成 | SDK、扫码键广播、WMS/ERP 对接方式 |

> 型号后缀和配置以官方资料为准，本文只给选型框架。

## 二、部署前先定业务链路

1. **采集**：扫什么码、在什么位置扫、是否需要 DPM。
2. **校验**：本地校验还是服务端校验，断网时是否允许缓存。
3. **上传**：实时上传还是批量上传，失败如何重试。
4. **呈现**：操作员看到的是成功/失败、下一步任务还是异常提示。
5. **管理**：设备注册、应用下发、版本升级、日志回收。

## 三、无线与续航

- 仓库和产线要做**漫游测试**，不是只在 AP 旁边测速。
- 金属货架、冷库、强干扰环境要单独评估。
- 按班次计算续航，并预留换电时间。
- 充电座位置要跟作业动线匹配，否则设备会“回座率”很低。

## 四、系统集成方式

常见三种：

- **广播/键盘模拟**：PDA 把扫码结果当键盘输入，接入简单，但格式控制弱。
- **SDK 集成**：业务 App 直接调用扫码服务，可控性强，需要开发。
- **中间件/服务端**：PDA 只负责采集，校验与业务逻辑放服务端，便于统一升级。

## 五、上线验收清单

- [ ] 实际货品、实际标签、最差码连续扫描
- [ ] 全区域 Wi-Fi 漫游与断网重连
- [ ] 一个完整班次的续航
- [ ] 与 WMS/ERP 的收发货、盘点、追溯流程
- [ ] 异常码、重复码、离线缓存的处理
- [ ] MDM 下发、升级、日志回收
