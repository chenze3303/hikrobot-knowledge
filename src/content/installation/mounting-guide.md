# 安装角度、工作距离与视野计算

同一个读码器，装对了和装错了，读码率可能差出一个数量级。安装阶段重点控制三件事：视野、距离和角度。

## 一、先算视野，再定位置

```text
FOV = WD × 传感器尺寸 / 焦距
```

反推安装距离：

```text
WD = FOV × 焦距 / 传感器尺寸
```

例：传感器宽 5.7 mm，镜头 8 mm，需要覆盖 200 mm 宽：

```text
WD ≈ 200 × 8 / 5.7 ≈ 281 mm
```

实际安装还要预留 10%–20% 的视野余量，抵消工件漂移和支架误差。

## 二、角度怎么摆

- 尽量让镜头光轴垂直于码面。
- 必须倾斜时，控制在较小角度，避免透视变形。
- 金属、玻璃、覆膜表面要避开镜面反射角。
- 读码器与光源分侧安装，减少直射反光。

> 经验做法：先固定读码器，再用手持光源在工件周围移动，找到反光最小的入射角，最后把光源固定到该位置。

## 三、工作距离与景深

- 工作距离不是越远越好，远距离会放大振动和杂光影响。
- 景深要覆盖工件高度波动，薄件高节拍场景尤其要注意。
- 近距离安装时，确认镜头最短物距和调焦行程。
- 支架要刚性足够，避免设备自身振动。

## 四、常见安装错误

| 现象 | 可能原因 |
| --- | --- |
| 图像一半亮一半暗 | 光源角度不对或遮挡 |
| 码边缘发虚 | 对焦不准或景深不足 |
| 读码率随位置变化 | 视野余量不足 |
| 偶尔全黑 | 触发时序或频闪不同步 |
| 反光斑遮住码 | 入射角接近镜面反射 |

## 五、安装验收

- [ ] 视野覆盖最大工件并留余量
- [ ] 工作距离在镜头调焦范围内
- [ ] 光轴角度与反光可控
- [ ] 支架无松动、无共振
- [ ] 线缆不遮挡视野、不承受拉力
- [ ] 防护罩不反光、不积尘
