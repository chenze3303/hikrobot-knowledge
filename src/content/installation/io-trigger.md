# I/O 接线与光电触发

固定式读码器常见的“读不到”，不是算法问题，而是触发时刻不对。触发系统要解决三件事：什么时候触发、触发几次、结果怎么回。

## 一、先确认电气类型

- 读码器输入通常支持 PNP/NPN 或干接点，具体以手册为准。
- 光电传感器有 PNP 和 NPN 两种输出，必须与读码器输入类型匹配。
- 避免把 24 V 直接接入不支持的输入。
- 共地、屏蔽和隔离要做好，防止产线干扰。

## 二、典型接线

```text
光电传感器（PNP） → 读码器 Trigger Input+
读码器 Trigger Input- → 0 V
读码器 Output → PLC 输入或指示灯
```

> 接线前断电，核对引脚定义。不同型号的线缆颜色不同，不要按颜色硬套。

## 三、触发时序

1. 工件到达触发位置，光电输出有效。
2. 读码器收到触发，开始曝光。
3. 曝光结束，算法读码。
4. 输出结果，等待下一次触发。

要确认：

- 触发位置在码完全进入视野之后。
- 触发脉宽满足读码器要求。
- 连续触发之间留足处理时间。
- 回传结果不阻塞下一次触发。

## 四、常见问题

| 现象 | 排查 |
| --- | --- |
| 完全不触发 | 输入类型不匹配、接线错误、触发模式未开 |
| 偶尔触发 | 光电抖动、脉宽不足、干扰 |
| 触发但无结果 | 曝光/读码未完成、输出未配置 |
| 重复触发 | 光电回波、PLC 重复发送、去抖不足 |
| 结果错位 | 触发与工件不对应，检查光电位置 |

## 五、调试建议

- 先用软件触发确认读码链路正常，再接硬件触发。
- 用示波器或读码器 I/O 监视确认触发波形。
- 在 PLC 侧记录触发计数和结果计数，排查丢触发。
- 产线提速后重新验证触发时序。
