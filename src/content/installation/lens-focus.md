# 镜头选型与对焦：别让景深拖后腿

镜头是读码器的“眼睛”。焦距选错，视野不对；光圈开太大，景深不够；对焦不准，边缘全糊。

## 一、焦距怎么选

```text
焦距 ≈ 工作距离 × 传感器尺寸 / 所需视野
```

| 需求 | 倾向 |
| --- | --- |
| 近距离、小视野 | 短焦（如 5–8 mm） |
| 中距离、常规视野 | 中焦（如 12–16 mm） |
| 远距离、大视野 | 长焦（如 25 mm 以上） |

先确定安装空间和工作距离，再反推焦距。不要先买镜头再凑安装位置。

## 二、光圈与景深

- 光圈越小（F 值越大），景深越大，但进光量减少。
- 光圈越大，进光量足，但景深变浅。
- 高节拍运动场景需要短曝光，往往要开大光圈并加强补光。
- 工件高度波动大时，优先保证景深。

## 三、对焦步骤

1. 把实际工件放在工作距离处。
2. 打开实时图，放大码区。
3. 缓慢调整焦距，直到码边缘最锐利。
4. 在最近和最远工件位置分别检查。
5. 锁紧镜头，防止振动导致跑焦。

> 不要用打印纸测试码对焦。实际工件的材质、反光和纹理才是真实成像条件。

## 四、常见问题

- **中心清晰、边缘模糊**：镜头分辨率或像面不平，尝试缩小光圈。
- **最近清楚、最远模糊**：景深不足，缩小光圈或调整安装距离。
- **整体发虚**：对焦不准、镜头松动或防护窗污染。
- **亮度不均**：镜头暗角或光源角度问题。

## 五、维护提醒

- 定期检查镜头锁紧螺丝。
- 清洁镜头时使用无尘布和合适清洁液。
- 防护窗划伤会永久降低成像质量，必要时更换。
