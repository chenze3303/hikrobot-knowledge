# 光源与补光：反光、DPM 与运动模糊

很多人把读码问题归因于算法，实际上是光没打好。光源选择要看三件事：表面、码型、运动。

## 一、按表面选光

| 表面 | 推荐光源 | 目的 |
| --- | --- | --- |
| 金属镜面 | 同轴光、偏振光 | 压制镜面反射 |
| 拉丝/纹理金属 | 低角度光 | 强化凹凸边缘 |
| 覆膜标签 | 漫射环形光 | 均匀照明，减少光斑 |
| 玻璃/透明包装 | 背光或偏振 | 提高码与背景对比 |
| 曲面工件 | 穹顶光/多角度光 | 减少阴影和高光 |

## 二、DPM 的打光逻辑

DPM 码靠凹凸而不是颜色对比。低角度光能让凸起和凹坑产生阴影，从而形成可识别边缘。

- 点阵/激光打标：低角度光优先。
- 镜面 DPM：同轴光或偏振光。
- 低对比度：多角度组合光，或多次曝光。

## 三、运动场景要频闪

运动读码时，持续光会限制曝光时间。频闪光源可以在极短时间内提供高亮度：

- 与相机曝光同步
- 频率覆盖最高线速
- 亮度可调，避免过曝
- 触发延迟可调

如果没有频闪，优先缩短曝光并提高常亮光源亮度，但要评估散热和寿命。

## 四、常见问题

- **中间亮、四周暗**：光源太小或距离太近，改用更大面积光或提高安装高度。
- **周期性明暗**：光源与相机频率不同步，调整频闪或曝光。
- **反光斑移动**：光源角度与工件位置变化，改为漫射或偏振。
- **图像发灰**：环境光干扰，加遮光罩或提高光源占比。
