# 误读、漏读与重复读

三类问题经常被混在一起：误读是读错，漏读是没读到，重复读是同一码输出多次。处理方式完全不同。

## 一、误读

可能原因：

- 码制勾选过多，读到了相似码
- 图像噪声导致模块误判
- 低质量阈值放得太松
- 多码场景没有限定 ROI

处理：

1. 只勾选实际码制。
2. 提高质量阈值。
3. 启用校验位。
4. 限定 ROI。
5. 对结果做前缀/长度校验。

## 二、漏读

可能原因：

- 码不在视野或 ROI
- 曝光/对焦问题
- 触发时机不对
- 码质量太差
- 读取超时太短

处理：

1. 看原图确认码是否清晰。
2. 调整触发位置。
3. 增加重试次数。
4. 改善光源。
5. 适当延长读取超时。

## 三、重复读

同一码被多次输出，常见于：

- 内触发连续读码
- 工件停留时间过长
- 多码区域重叠
- 上位机未去重

处理：

- 读码器端开启时间去重。
- 上位机按码内容 + 时间窗去重。
- 用触发一次只读一次。
- 多码时限定区域。

> 去重只能在一端做主规则，两端都做容易把正常码也过滤掉。

## 四、调参顺序

1. 先保证图像质量。
2. 再限定码制和 ROI。
3. 再调质量阈值和校验。
4. 最后处理去重和输出。

## 五、验收指标

- 正常码读码率
- 最差码读码率
- 误读率
- 重复读率
- 平均处理时间

不要只看“读到了”，要把四类指标分开统计。
