# 软件、固件与文档下载

软件和固件版本不匹配，是很多“莫名其妙连不上”的根源。下载前先确认型号和版本。

## 一、官方入口

- 海康机器人机器视觉下载中心
- 产品页的“资料下载”
- V 社区的技术帖与教程

> 优先使用官网和官方社区，不要从不明来源下载固件或 SDK。

## 二、下载前确认

| 项目 | 要确认 |
| --- | --- |
| 型号 | 机身铭牌上的完整型号 |
| 固件版本 | 当前版本与目标版本 |
| 软件版本 | IDMVS 大版本是否兼容 |
| 系统 | Windows 版本、32/64 位 |
| SDK | 与固件/软件匹配的版本 |
| 文档 | 用户手册、通讯手册、规格书 |

## 三、版本选择原则

- 产线设备优先稳定版本，不追最新。
- 新版本先在一台设备验证。
- 同一产线尽量统一版本。
- 保留安装包和校验值。
- 升级前备份参数。

## 四、下载后检查

- 文件大小与官网一致。
- 校验值（如提供）。
- 安装包签名与来源。
- 解压后目录结构完整。
- 版本说明中的已知问题。

## 五、常见问题

- **软件连不上设备**：版本不兼容或固件过新。
- **固件升级失败**：型号不匹配、文件损坏、断电。
- **手册找不到**：按完整型号搜索，不要只搜系列名。
- **SDK 示例跑不通**：运行时缺失、位数不一致、权限不足。

## 六、资料归档建议

按“型号/版本/日期”归档：

```text
ID2000/
  firmware/
  idmvs/
  manual/
  sdk/
  config-backup/
```
