# 清洁与日常保养

读码器不是装完就不管。灰尘、油污、切削液和静电会慢慢降低成像质量，最终表现为“读码率越来越低”。

## 一、清洁对象

- 镜头前防护窗
- 镜头本体
- 光源外罩
- 散热风扇/散热片
- 线缆接头
- 安装支架

## 二、清洁方法

1. 断电。
2. 用干燥无尘布先去除浮尘。
3. 油污用合适清洁液，避免腐蚀性溶剂。
4. 镜头用镜头布，沿一个方向轻擦。
5. 不要用尖锐物刮擦防护窗。
6. 清洁后确认无残留、无划伤。

> 不同防护等级和材质适用清洁方式不同，以手册为准。

## 三、周期建议

| 环境 | 建议周期 |
| --- | --- |
| 洁净车间 | 每周检查，按月清洁 |
| 一般产线 | 每周清洁 |
| 粉尘/油污环境 | 每班或每日检查 |
| 户外/高湿 | 每周检查，注意结露 |

## 四、日常检查清单

- [ ] 图像亮度是否正常
- [ ] 是否有新的反光斑
- [ ] 防护窗是否划伤
- [ ] 线缆是否松动
- [ ] 支架是否松动
- [ ] 散热是否正常
- [ ] 读码率是否下降

## 五、备件与记录

- 保留备用防护窗、线缆和光源。
- 记录清洁日期、人员和异常。
- 读码率连续下降时，先查污染和光源衰减，再查算法。
