# 读码器术语表

跨部门沟通时，术语不一致会直接导致选型和验收偏差。下面是最常用的一组。

## 光学

| 术语 | 含义 |
| --- | --- |
| 视野 FOV | 读码器能覆盖的物理范围 |
| 工作距离 WD | 镜头到工件的距离 |
| 景深 | 保持清晰的距离范围 |
| 焦距 | 镜头的光学参数，决定视野 |
| 光圈 | 控制进光量和景深 |
| 分辨率 | 传感器像素数，不等于精度 |
| 像素精度 | 单像素对应的物理尺寸 |

## 码与识别

| 术语 | 含义 |
| --- | --- |
| 一维码 | 条形码，如 Code 128、EAN |
| 二维码 | QR、Data Matrix、PDF417 等 |
| DPM | 直接零部件标记，直接打在工件表面 |
| 最小模块 | 码中最小单元尺寸，常以 mil 表示 |
| 纠错等级 | 二维码容忍污损的能力 |
| 读码率 | 成功读取次数 / 触发次数 |
| 误读率 | 读错次数 / 读取次数 |
| 漏读 | 有码但未读到 |
| 重复读 | 同一码被多次输出 |

## 触发与通讯

| 术语 | 含义 |
| --- | --- |
| 内触发 | 读码器按内部节拍连续采集 |
| 软件触发 | 上位机发送命令触发 |
| 硬件触发 | 光电/PLC 通过 I/O 触发 |
| TCP 触发 | 通过网络字符串触发 |
| PNP/NPN | 数字量输出的两种极性 |
| 握手 | 触发、忙、完成的状态交互 |
| 粘包 | 多条报文在一次接收中出现 |

## 安装与维护

| 术语 | 含义 |
| --- | --- |
| 镜面反射 | 高反光表面形成的亮斑 |
| 频闪 | 与曝光同步的短时高亮光源 |
| 偏振 | 过滤特定方向反射光 |
| 防护等级 | 防尘防水能力，如 IP67 |
| 回退 | 固件/参数恢复到旧版本 |

## 使用建议

- 选型文档统一写“最小模块”，不要只写“码很小”。
- 验收统一写“读码率”和“误读率”，不要只说“能读”。
- 通讯文档统一字段名和分隔符。
- 维护记录统一型号、序列号和固件版本。
